# Expo SDK compatibility

This project is temporarily pinned to Expo SDK 54 so it can run in the App Store version of Expo Go on a physical iPhone.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code. Do not upgrade the Expo SDK until the physical-device distribution path is changed from the App Store version of Expo Go and that decision is documented.
